# URAL brand assets

Generated from the supplied `URAL Logo Concepts.html` SVG geometry. No AI redraw or raster tracing was used; the exports preserve the specified paths, colors, and proportions.

## Master vectors
- `svg/ural-wordmark.svg` — transparent ivory wordmark
- `svg/ural-wordmark-navy.svg` — transparent navy wordmark
- `svg/ural-ascent-mark.svg` — transparent ivory symbolic mark
- `svg/ural-ascent-mark-navy.svg` — transparent navy symbolic mark
- background-specific SVGs are included for ivory and emerald surfaces

## PNG sizes
The `png/` folder includes the HTML sizes: wordmark 760, 300, 260, 220, 120, 64, 190, 96, 40px; Ascent mark 220, 170, 92, 84, 76, 48, 34, 18px.

## Favicon and app icons
The `favicon/` folder includes SVG, ICO, and PNG exports at 16, 32, 48, 64, 180, 192, and 512px, plus `site.webmanifest` and an HTML integration snippet.

## Palette
- Night Navy `#0B1426`
- Pilgrim Gold `#F6B73C`
- Ivory `#F5F1E8`
- Emerald `#0F4A3F`

## Recommended usage
Use the wordmark for headers, print, and itinerary/business-card contexts. Use the Ascent mark for favicon, app icon, and WhatsApp/avatar contexts. On a light background use the navy-on-ivory version; on a navy or emerald surface use the ivory version.
