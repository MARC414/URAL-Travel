# GSC read — 22–31 October 2026

**First real search data the project has had.** Owner export, uploaded 2 November
2026, unmodified, in `gsc-2026-10-22_2026-10-31/`. Checked against the 25 October
audit's assumptions; several of those assumptions do not survive contact with the
numbers.

## 0. The headline

| Metric | Value |
| --- | --- |
| Window with data | **10 days** (22–31 Oct 2026), not 3 months |
| Clicks | **2** |
| Impressions | **1,246** |
| CTR | **0.16%** |
| URLs in sitemap | 262 (131 EN + 131 BN) |
| Impressions per URL, per day | **≈0.47** |

Two clicks in ten days. That is the entire site. Every planning decision from
here has to start with that number, because it is not a content problem — a
site with 262 URLs and 1,246 impressions does not have a coverage gap. It has a
visibility problem.

**Caveat, stated plainly:** the `Filters.csv` says `Date: Last 3 months`, but
`Chart.csv` contains only 22–31 October, and the country total (1,246) matches
the chart total exactly. Either the property was only verified on 22 October, or
the date filter did not apply to the whole export. **Confirm which.** If the
property is genuinely 10 days old, nothing below is a trend — it is a snapshot,
and no decision should be made on a 10-day window alone.

## 1. The finding that matters: the Hajj/Umrah cluster does not earn traffic

| | |
| --- | --- |
| Cluster impressions (25 URLs incl. BN) | **97** — 7.8% of site |
| Cluster clicks | **0** |
| Typical cluster position | **4.0 – 17.0** (page 1) |
| Best cluster page | `/bn/blog/makkah-madinah-badr-taif-historical-ziyarah-taxi-guide` — 15 impressions, position 7.5, 0 clicks |

The cluster is not failing because it is incomplete. **It is already on page
one and nobody clicks.** Its best pages are at positions 4–8 with zero clicks,
which means the constraint is demand (almost nobody searches these exact
phrasings yet) and click-through (the snippets do not persuade), not coverage.

This is the direct answer to the breadth-versus-depth question: at 97
impressions across 25 URLs, the cluster is averaging **under four impressions
per URL over ten days.** A eighteenth article will not move that. Writing
twenty more short articles into this cluster buys approximately nothing.

A page at position 8 with 59 impressions and zero clicks is not a ranking
problem. It is a **title-and-snippet problem**, and it is the cheapest possible
thing to fix: no new articles, no new URLs, no new sources. Rewrite 37 titles
and descriptions and the same impressions start producing clicks.

## 3. The single biggest query opportunity

| Query | Impressions | Position | Clicks |
| --- | --- | --- | --- |
| বাংলাদেশের পাসপোর্ট দিয়ে ভিসা ছাড়া কোন কোন দেশে যাওয়া যায় 2026 | **37** | **10.2** | **0** |

This is the largest single query on the site, it is in Bengali, it is at
position 10.2 — the very bottom of page one — and it earns nothing. The page it
maps to (`/bn/visa-free-countries`, 54 impressions, position 9.2) already
exists and already ranks. Moving it from 10.2 to 6 would plausibly be the single
highest-value hour of work available to this project, and it requires no new
content.

Note also: **the strongest demand signal on the whole site is Bengali, and it is
not about Hajj.** 59 of the top 100 impressions are on `/bn/` URLs.

## 4. Audience: Bangladesh, mobile, and it is not close

| Country | Impressions | Clicks |
| --- | --- | --- |
| Bangladesh | 656 (53%) | 1 |
| United Kingdom | 110 | 0 |
| United States | 62 | 0 |
| UAE | 57 | 0 |
| Saudi Arabia | 51 | 0 |

| Device | Impressions | CTR | Avg position |
| --- | --- | --- | --- |
| Mobile | 732 (59%) | 0.14% | 13.66 |
| Desktop | 514 (41%) | 0.19% | 40.81 |

Mobile ranks **27 positions better** than desktop. The site is being found on
phones in Bangladesh and losing on desktops — consistent with a new domain being
shown to mobile first. Write and measure for mobile; ignore desktop position for
now.

The UK (110 impressions, 0 clicks) is the second market and is *not* being
served by any deliberate content. That is worth a decision later, not now.

## 5. Queries: a very long, very thin tail

| Measure | Value |
| --- | --- |
| Unique queries | 202 |
| Queries with ≥5 impressions | **11** |
| Impressions at position 50+ | 178 (47%) |
| Impressions at position 21–50 | 119 (31%) |

Half the query surface is beyond position 50 — the site is being *seen* for
hundreds of things it is nowhere near ranking for. That is normal for a new
domain and it is the clearest evidence that **authority, not inventory, is the
binding constraint.**

Outside the top query, demand clusters on flights (`dhaka to kathmandu flight`,
`dhaka to male flight`, `dhaka to kuala lumpur flights`, `dac to dxb flight`)
and visas (`uae visit visa for bangladeshi`, `thai visa fee for bangladeshi`).

## 6. What this changes in the plan

| Previous position | Revised position |
| --- | --- |
| "The main cluster is complete; add short articles across many topics." | The cluster is complete **and it earns nothing.** Breadth is not the constraint. Do not add articles to it until CTR is fixed. |
| "Measurement is broken, so publish slowly." | Measurement is no longer broken for search. It is broken for *conversions* only. Publishing can resume on evidence. |
| Tawaf article passes G1–G7 on a demand signal. | **G3 is now questionable.** It shipped on an owner request and a reel gap, not on a GSC query. Keep it — it is written and gated — but do not treat it as validated. It will show in the 90-day check. |
| Article B (Hajj rites) is next. | **Deprioritise.** The cluster earns 97 impressions. Article B would earn a fraction of that. |
| `/visa/saudi-arabia-visa` is the highest-value missing URL. | **Still true, but no longer first.** The visa-free page is already ranked and already wasting 114 impressions. Fix that first — it is a day's work, not a build. |

### Revised order of work

1. **Rewrite the 37 zero-click page-1 titles and descriptions.** Especially
   `/visa-free-countries` and `/bn/visa-free-countries`. Highest return per hour
   on the entire list, and it needs no new content.
2. **Push the Bengali visa-free query from 10.2 into the top 5.** Internal
   links, a clearer H1, an answer-first block in the first 100 words.
3. **Get GTM conversion events live** (owner, in progress) so the next export
   can be judged on enquiries rather than clicks.
4. **`/visa/saudi-arabia-visa`** — still the right structural build, now third.
5. **Article B** — hold. It fails G3 on today's evidence.
