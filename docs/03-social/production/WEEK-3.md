## SOC-006 — Data eSIM নিলেই কি ব্যাংকের SMS আসবে?

- **Format / language:** REEL / bn
- **Source:** [Travel eSIM & Schengen Travel Insurance Guide for Bangladeshi Travelers (2026 — Umrah, Asia & Europe)](https://uraltravel.co.uk/blog/best-travel-esim-and-schengen-travel-insurance-bangladesh-guide) — Data-only eSIM and SMS/OTP distinction
- **Decision / evidence:** Data connectivity and SMS to the bank-registered number require different arrangements. (SF-01; USEFUL SECONDARY at the stated scope.)
- **Status / gate:** DRAFT — PRODUCTION / SOURCE CHECK; G-01
- **Funnel / KPI:** PLANNING; Watch retention; saves; relevant connectivity questions
- **Visual direction:** Neutral phone illustration with generic data and message icons; no brand recommendation or live bank screen.
- **Do not claim:** Do not link the cash/card guide with the unresolved eSIM-OTP CTA; no claim that every eSIM lacks SMS.

### Spoken script

**Target:** roughly 35–50 seconds including the hook; time an actual Bengali read and trim pauses/repetition rather than speed-reading.

Data eSIM নিলেই কি ব্যাংকের SMS আসবে?

বিদেশে internet চালু হলেই ব্যাংকের SMS আসবে—এটা ধরে নেবেন না। Data-only eSIM আপনাকে mobile data দেয়; নিজের থেকে ব্যাংকে নিবন্ধিত নম্বরের SMS এনে দেয় না। যাওয়ার আগে ব্যাংক ও নিজের mobile operator-কে জিজ্ঞেস করুন, ওই নম্বরে OTP পাওয়ার ব্যবস্থা কী। যে eSIM নেবেন, তার plan-এ data, calls বা SMS কোনটা আছে, আর আপনার phone support করে কি না—মিলিয়ে নিন। কাউকে OTP দেবেন না।

### Shot / text plan

- 0–3s: Data eSIM ≠ bank SMS.
- 3–18s: two columns—Internet and registered mobile number.
- 18–35s: bank + operator + exact plan checks.
- Final: Check before travel; no OTP on screen.

Use the spoken wording for subtitles. Proofread auto-captions manually. The cut is a draft until the producer checks pacing.

- **Source:** [Existing airport-code lookup tool](https://uraltravel.co.uk/tools/airport-codes) — InteractiveTools airport directory: DAC / KTM / DXB examples; no desk functionality promoted
- **Decision / evidence:** Use the airport code and full airport name to verify a quoted itinerary. (SF-05; USEFUL SECONDARY at the stated scope.)
- **Status / gate:** DRAFT — PRODUCTION / SOURCE CHECK; G-01; U-09 blocks tool/service CTA
- **Funnel / KPI:** AWARENESS; Saves; practical route questions; no website-action claim
- **Visual direction:** One 4:5 graphic with three code/name pairs. Source credit in caption only; no fare-request button or screenshot.
